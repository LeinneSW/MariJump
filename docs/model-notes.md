# 모델 구성 및 변환 기록

Unity 6000.5.4f1과 URP 17.5.0으로 구성한 모델 확인용 프로젝트입니다.

## 열기

Unity Hub에서 이 폴더를 추가하고 `Assets/Scenes/MariPreview.unity`를 엽니다.
캐릭터는 `Assets/Mari/Prefabs/MariIdol.prefab`, 무대는 `Assets/Mari/Prefabs/IdolStage.prefab`입니다.
샘플 씬은 정적인 모델 미리보기이며 게임 조작과 애니메이션은 아직 없습니다.

## 변환 결과

| 항목 | 내용 |
|---|---|
| 원본 | 루트 ZIP 안의 `source/CH0273.zip`, OBJ와 PNG |
| 캐릭터 | 메시 그룹 10개, 삼각형 30,172개 |
| 무대 | 메시 그룹 1개, 삼각형 7,055개 |
| 크기와 축 | 발바닥을 원점에 맞추고 Y축을 위로 변환, 헤일로 포함 약 1.2m |
| 재질 | 원본 RGB를 표시하는 URP Unlit 재질, 입은 알파 컷아웃 |
| 보존 | 원본 ZIP 유지, PNG 픽셀과 UV 및 노멀 유지 |

## 관절과 가능한 애니메이션

이번 ZIP에는 뼈대, 스킨 웨이트, 블렌드 셰이프, 애니메이션 클립이 모두 0개입니다.
OBJ 그룹의 `RootNode`는 이름이며 관절을 뜻하지 않습니다.

| 동작 | 현재 자료로 가능한 범위 |
|---|---|
| 통째로 점프, 회전, 흔들림, 늘이기 | 프리팹의 위치, 회전, 크기를 애니메이션으로 조절할 수 있습니다. |
| 헤일로 이동과 회전 | 별도 메시여서 독립적으로 움직일 수 있습니다. |
| 입 모양 전환 | `mouth.png`의 8×8 격자에서 UV 오프셋을 바꾸는 방식이 가능합니다. 일부 칸은 대체용 도형입니다. |
| 고개 움직임 | 얼굴과 머리카락 등을 묶고 회전 중심을 만들어야 합니다. 목의 자연스러운 변형에는 리깅이 필요합니다. |
| 팔꿈치, 무릎, 손가락, 걷기와 달리기 | 몸체에 뼈대와 스킨 웨이트를 새로 넣어야 합니다. |
| 눈 깜빡임, 세밀한 표정 | 추가 텍스처나 메시 변형, 블렌드 셰이프 제작이 필요합니다. |
| Humanoid 애니메이션 재사용 | 현재는 불가능하며 사람형 리깅과 Avatar 매핑이 필요합니다. |

위 표는 제작 가능한 범위입니다. 완성된 동작 클립이 포함되어 있다는 뜻은 아닙니다.

## 재변환과 검사 자료

Python으로 `Tools/prepare_model.py`를 실행하면 ZIP에서 Unity용 OBJ와 텍스처를 다시 준비합니다.
Unity 메뉴의 **마리 점프 > 모델과 미리보기 씬 다시 만들기**는 해당 프리팹과 샘플 씬을 재생성합니다.
원본 분석은 `docs/model-analysis.json`, Unity 검사 결과는 `docs/unity-import-report.json`에 기록합니다.
출처와 변환 내용은 `Assets/Mari/SOURCE.txt`에 있습니다.
